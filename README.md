# Emovere

> **Emovere is a self-knowledge journal that complements, and never replaces, professional care. It is not a medical device.** It does not diagnose, assess risk, prescribe or monitor anyone.

A private, local-first mobile app for adults (pt-BR, Brazil only in Phase 1): quick check-ins, a journal and preparation for the conversation with a professional. Everything stays on the device. "Emovere" is a working name.

## If you are in crisis

Emovere is not an emergency service. In Brazil, call **CVV 188** (24 hours, free) or **SAMU 192**, or go to the nearest UPA or emergency room.

## Never commit real data

No real entries, check-ins, journal text, screenshots of real use or exported files belong here — not in code, tests, fixtures, issues or prompts to AI tools (ADR-009, ADR-029). Use only the synthetic personas described in the docs.
