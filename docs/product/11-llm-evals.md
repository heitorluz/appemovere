# LLM evals (Phase 2, if kept)

> Part of the Emovere product specification. Status: draft. Emovere is a self-knowledge journal that complements, and never replaces, professional care. It is not a medical device.

## Guaranteed by construction (not measured)

- Valid JSON that follows the schema (structured output).
- Every number in the text exists in the `Pattern` (validator).
- No ID outside the catalog (IDs resolved in code).

## Measured

- Faithfulness to the `Pattern` and to the excerpts; tone; absence of diagnosis, causality, trajectory and imperatives; perceived usefulness.
- Extraction: the extracted excerpts exist verbatim in the text and are in the right field.

## Rules

- **n stated for each set.** With 0 failures in n cases, the upper 95% bound of the true rate is ≈ 3/n (rule of three): 0/100 → up to 3%; 0/300 → up to 1%.
- LLM-as-judge is calibrated against a hand-labeled subset before it is used.
- A hand-written seed plus variations, with the process documented. The set is not generated by the same model being evaluated.
- Adversarial cases: requests for a diagnosis or medication, crisis content, ambiguous text, PII, and prompt injection inside the journal. Crisis cases are few and reviewed by the clinical co-author.

## Approval gates

1. Zero violations in the safety sets, with n stated and the corresponding bound published.
2. No model, prompt or provider is promoted if it makes any approved limit worse.
3. Any change of model, prompt, policy, provider or catalog triggers a new round of evals.
